# Jimm Renaissance

Форк мультипротокольного клиента Jimm Aspro для J2ME для поддержки пользовательских проектов. Лицензирован по GNU GPL 2.0

## Поддерживаемые и адаптированные протоколы

* MRIM (Mail.ru Agent)
* ICQ
* Jabber

## Изменения по сравнению с Jimm Aspro

* В настройках протокола (профиля) можно указать сервер и порт 
* Сервера по умолчанию выставлены на известные проекты
  * Для MRIM - mrim.su
  * Для ICQ - Проект KICQ
* Новая встроенная тема

## Как собрать?

1. Установите J2ME для Intellij по инструкции для [Windows](https://github.com/ading2210/setup-j2me-sdk/blob/main/windows_setup.md)
2. Установите Apache Ant версии 1.7.0, в ant.bat в начало файла после `@echo off` пропишите:
```
set JAVA_HOME={ПУТЬ ДО JDK 1.8.0}
```

Отредактируйте файл `config/sysdirs.properties`.

Для непосредственной сборки выполните команду `ant`
